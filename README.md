# Universityy — Қазақша / Русский

1. Жоба папкасында `npm install` командасын орындаңыз.
2. `npx expo start --clear` командасын орындаңыз.
3. Android эмуляторы ашық болса, `a` басыңыз.
4. Тілді бірінші Onboarding экранында немесе Профиль → Тіл бөлімінде таңдаңыз.

Тіл AsyncStorage ішінде сақталады. Бұл жоба бастапқы ZIP-тен қалпына келтірілді: бастапқы архивте package.json болмағандықтан жаңадан жасалды. Экрандардағы кейбір бастапқы әрекеттер демонстрациялық болып қалады (мысалы, нақты серверлік кіру жүйесі жоқ).
